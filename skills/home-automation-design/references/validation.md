# 验证、发布与维护

## 证据范围

把配置/源码声明、运行注册、当前状态、历史轨迹和实物反馈分开。源码审计不能证明全部物理效果；插件 idle、监听数量正常也不能证明规则逻辑正确。列出已读规则、停用规则、重复入口、未知云端/固件规则及取证时间。

按改动验证行为，不写仅匹配关键词或复刻实现的假测试。可用自动化 trace、事件回放、虚拟状态机、离线推演与用户观察，各自标明局限。不要在生产机写假状态来模拟有人/无人，更不能为测试发送开锁、投喂、加热等无关动作。

## 最小场景集

| 场景 | 应有结果 |
|---|---|
| 空白 HA 没设备/没有管理工具 | 引导维护连接和设备接入；不声称已审计源码，不生成虚构实体。 |
| 只有 PIR，住户静坐 | 不把静默当可靠无人，保持必要照明或使用已说明的弱替代策略。 |
| 配置好的关键传感器不可用 | 与未购买传感器分开处理，未知不能触发要求明确无人/闭合的动作。 |
| 已启用餐厅保护客厅；分别触发计时、电视结束、光照与模式变更 | 所有关灯/降亮入口执行相同保护；保护现有灯光不默认主动开灯。 |
| 未启用跨房间联动，餐厅有人、客厅无人 | 按各区规则处理，不自动增加餐厅保护、主动开灯或共同退出。 |
| 先暗后有人；先有人后变暗；关帘变暗 | 均唤醒同一判断，按模式和人工保持开启选定灯具，不依赖唯一事件顺序。 |
| 开灯后照度升高、云影、人在场主动关灯 | 不反复开关；人工抑制覆盖巡检与光照回调，按约定退出。 |
| 主卧/次卧/儿童房共用逻辑，设备及参数不同 | 采用同一契约与显式覆盖项，不漂移为三套规则。 |
| 同床一人起夜、访客睡眠、白天午睡、轮班清晨睡 | 不由单人离床或全屋晨间直接退出所有睡眠保护。 |
| 学习/工作只灯光不同；书桌静坐；短暂离席返回 | 复用活动逻辑与场景；PIR 静默不直接退出，旧延迟不覆盖新活动。 |
| 多人同时占用、重复上报、重启和未知区间 | 按所选口径累计一份房间时长；不按消息次数加时，不虚构未知时长。 |
| 占用达清扫阈值，但有人睡、门态未知或机器人忙 | 只保留需求，执行前统一重读，未满足条件不启动。 |
| 分区部分完成、任务中新增占用、重复完成事件 | 仅结算已确认范围与类型，保留新增量，不重复扣除；详见占用清扫参考。 |
| 人工选择夜间后短暂离开又回来 | 人工保持不被新人体事件抹掉；到约定退出事件或用户退出才恢复。 |
| 空卧室门关、卧室有人睡、占用未知的晨间 | 三种分支不同；时间触发不强行开有人睡眠的帘，也不拿门关永久阻止空房恢复。 |
| 新人工命令到达，旧关灯任务已排队 | generation/owner 重读使旧任务失效，即使取消 scheduler 来不及。 |
| HA 在截止时间之前/之后离线恢复，反复重载 | 绝对截止时间不延长；幂等任务对账，非幂等任务不盲重放，不重复监听。 |
| 多设备动作部分失败 | 逐设备确认与补偿，不宣称整个事务成功；恢复不覆盖新人工意图。 |
| 故障窗帘持续 opening/closing | 只按已验证型号适配，保留原始反馈和超时出口，不推广到其他型号。 |
| 同一物理机由 Xiaomi Home 和 MIoT 接入 | 能力分别选权威，触发与导出去重；保留仍有消费者的集成。 |
| HomeKit 单桥超容量或含 accessory-only 类型 | 解释协议限制，保留主桥与必要例外，不少导或默默重建全部配对。 |
| 扫地机声明 Clean Area 但地图房间表空 | 先调查源端房间获取，不能宣称 Matter 分区已就绪。 |
| Matter 多选两个分区 | 核对完整选择集合与实际命令；自定义批量元数据被正确处理，不只清扫最后一个。 |
| 设备离线多次抖动，恢复时上次动作未确认 | 通知去重、重试有上限，恢复动作不重复执行。 |

## 家庭上线与交付

先备份相关文件与配对信息，做配置/语法检查及需要的业务验证；再小范围启用。对存在相互写入的旧规则明确迁移顺序和回滚，不凭同名批量停用。新装 HA 先做少量无风险设备，随后按用户目标扩展。

重载/重启应与变更需要相匹配，遵守用户的观察要求。重连后先确认自动初始化完成，不能再手动启动同一 App。启动对账避免一次性向全屋发送开关/运动命令。

保持“为什么执行/被阻止”、输入健康、模式来源、任务截止时间、命令尝试/确认、失败出口可观察。按规模选择事件与周期补偿，不强制所有家庭固定频率扫描。

交付要包含：范围、版本、规则/能力映射、备份位置、验证方法与结果、未验证条件、用户操作与回滚。修改后再次对照目标行为，而非只检查错误日志为空。新的故障经验应形成有条件的规则，不不断累积为每个家庭都强制执行的清单。

## 技能分发

公开包只含通用技能、空白规划模板和使用说明；按明确清单组包，不递归打包家庭工作目录。家庭报告、源码快照、设备 ID、地图、日志、网络信息、令牌和配对材料留在私有位置。检查相对链接、YAML、版本、模板选择状态及敏感信息，并区分结构校验、离线场景审阅和实机验证。

说明支持技能安装的客户端、仅能读取文档的 AI 和无仓库读取能力的客户端各自的使用方法；读取说明不等于永久安装或已有 HA 访问权限。发布权限不包含修改家庭自动化的权限。
