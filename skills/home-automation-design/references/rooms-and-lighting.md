# 房间共用逻辑与照明

## 配置与建议默认值

复用决策逻辑，按房间绑定设备与偏好。下面是可供讨论的起点，不是部署授权：

| 选择 | 建议起点 |
|---|---|
| 卧室逻辑 | 主卧、次卧、儿童房共用契约，各房配置；差异以显式覆盖项记录。 |
| 自动睡眠推断 | 未确认策略前不启用；保留人工睡眠入口。 |
| 书房学习/工作 | 先共用书桌专注逻辑，按需选择不同场景；进入、退出或保护不同才拆模式。 |
| 短暂离席 | 可提议 10 分钟模式保持作为试用值，用户确认后才使用；灯光保持另配。 |
| 灯具/亮度/色温 | 用户选择，优先保留已有认可的场景；不预填某一家庭数值。 |
| 跨房间联动 | 默认各区独立，逐项选择方向、动作和保护范围。 |
| 人工关灯 | 默认暂时抑制该范围的自动重亮；保持到何时须有约定。 |

区分未讨论、建议待确认、已确认和不启用。既有家庭先保留明确偏好；建议默认值不能覆盖已有配置。

## 卧室

共用契约包含睡眠进入、起夜、起床退出、人工保持、午睡/轮班、晨间窗帘及故障降级。房间名称不决定行为，儿童房也不默认采用成人作息。设备和角色差异作为配置，不复制整套状态机。

逐房选择：

- 进入证据：床区/床压、灯态、门帘状态、时段及人工选择如何组合；持续时间、白天和夜晚门槛分别配置。明确哪些条件必需、可选或仅用于增强置信。
- 退出证据：床区无人持续多久、哪些灯属于正常照明/夜灯、亮度如何归一化、是否需要明确起床确认。某组灯打开只是可选证据，不自动等于全房起床。
- 午睡与轮班：允许白天睡眠，不由统一晨间时间强行退出。自动检测不到时保留人工入口。
- 起夜：短暂或较长离床、路径夜灯是否保持睡眠由家庭选择，不以一个固定最长离床时间推广到所有人。
- 多人与同床：任一确认的睡眠需求仍在时，保护对应区域；一人离床不代表所有人起床。不能仅靠一个床区传感器声称识别了每个人。
- 访客：可显式启用访客/临时睡眠保持，不依赖访客手机已登记。人工睡眠不会被短暂无人、再次有人或全屋同步静默清除。

不把固定秒数、亮度数值、关门或关帘要求当通用标准。覆盖关门时已在床、关门后上床、床区/灯态/门帘先后变化等顺序；每个相关变化都重新判断当前完整条件，不要求事件必须按唯一顺序发生。

未安装床区传感器时选择人工睡眠或已说明精度的弱推断。已安装但故障时进入未知分支，不自动切换成已确认无人。晨间分别处理空房、有人睡和未知；时间到了不自动开睡眠中的窗帘。

## 书房与书桌活动

“日常”作为基础活动，书桌专注承载学习/工作的共同保护。若学习、工作仅灯光不同，用同一活动逻辑加用户场景；若进入、退出、通知、设备或保持策略不同，可以配置独立模式，仍复用共同判断。

进入可由明确按键/界面选择，或验证过的书桌占用。只检测到有人时不能自行判断是在学习还是工作；使用已选场景或约定的默认场景。电脑开机、柜门打开等是否构成证据需由用户选择，不默认照搬。

退出支持明确结束，或可信离席持续达到约定时间。重新活动取消旧退出任务；模式保持与任务灯、空调等设备的保持分别配置。只有 PIR 时静默可能是静坐，不能将其直接当可靠离席。保持期限到达后仍要核对占用、来源和当前意图，不能机械退出。

## 照明：触发与判断分开

占用、照度、门帘等环境变化、活动模式、人工操作、保持到期及恢复对账均可唤醒判断。最终是否动作取决于当前证据和仲裁，不取决于“恰好是哪一个回调”。

| 事件顺序/状态 | 应判断的行为 |
|---|---|
| 已暗，随后确认有人 | 若场景允许、没有人工抑制，开启选定照明。 |
| 已有人，随后自然光降低或关帘变暗 | 同样重新判断并补光，不等待下一次有人事件。 |
| 有人且暗，模式/场景变化 | 按新需求计算；不覆盖仍有效的人工保持。 |
| 明确无人，光照降低 | 普通占用照明不自动开；迎宾、安防等需另行选择。 |
| 人在场，主动关灯或调整部分灯 | 识别人工意图，按约定范围保持，不被巡检/低照度立即撤销。 |
| 有人，传感器未知或数据不可信 | 使用约定降级；未知不直接当昏暗或无人。 |

“有人且暗”是照明需求，还须经过睡眠、观影、活动、人工保持及设备互锁。夜间路径光、正常照明、任务照明由用户选灯及参数；补光不默认打开全房所有灯。补光策略可选仅全关时开启、补充指定灯具、或调节已有灯具，明确人工调暗后的处理。

### 光照反馈与防振荡

- 开灯和关灯独立设计；光照回升不自动证明应该关灯。配置开/关阈值差、稳定时间及最短保持，按传感器实际单位与位置校准。
- 灯本身可能照到照度计。仅有双阈值并不能保证消除开关循环；需评估自然光参考传感器、经过验证的灯光影响补偿，或禁止用点灯后的混合照度直接触发自然光关灯。
- 云影、经过遮挡及占用抖动做稳定确认；不设置全家庭统一秒数。光照充足后的关闭/调暗策略单独选择，避免突然熄灭正在使用的任务灯。
- 人工关灯的抑制范围及退出方式要明确，例如确认离房后重置、到期重新判断或用户解除。模式保持结束不等于必须开灯。
- 自动动作引起的状态变化不是新的人工操作。难以区分来源时使用可解释的保守策略，不把所有反馈都当成用户意图。

无照度计可选太阳高度、时间和窗帘等弱替代，不声称知道室内实际照度；已配置照度计故障是另一分支。恢复后待输入稳定再参与判断。

## 跨房间联动

以小量具体问题确认，例如“餐厅用餐时是否保持客厅现有灯光？”后续再确认是否主动开客厅灯。分别记录来源区域、目标设备、保护/主动动作、有效模式和退出条件。

保护现有灯光不等于主动开灯；不允许关灯不等于不允许任何调光。厨房活动是否使餐厅进入用餐、厨餐是否共同退出、客厅是否跟随用餐，均为独立可选项。启用后，所有写入入口一致执行；未启用时不产生额外干预。
